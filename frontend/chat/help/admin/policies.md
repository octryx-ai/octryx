Which tool calls stop and wait for a person.

### What you do here
- Set the platform default: which risks and tools always need approval, and which never do.
- Let a Workspace add its own approval rules or inherit the default.
- See which MCP servers each Workspace may use.

### Next steps
- [Declare forbidden actions in Policies](/chat?area=admin&tab=cedarPolicies)
- [Set who may approve](/chat?area=admin&tab=approvalRule)
- [Manage MCP servers](/chat?area=admin&tab=mcp)

### Good to know
- **Forbidden** actions are declared in Policies; **who** may approve is the Approval rule.
- The MCP servers view is an overview only. An MCP server is **off** for a Workspace until it is allowed in that Workspace's connectors.
