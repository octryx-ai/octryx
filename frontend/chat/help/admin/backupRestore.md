---
title: Backup & restore
---

Export one Workspace's configuration and restore it into another.

### What you do here
- Create a backup of a Workspace and download it.
- Restore a backup file into a Workspace you choose.

### Next steps
- [Manage Workspaces](/chat?area=admin&tab=projects)

### What a backup holds
- One Workspace's configuration, actions and agents, plus the platform-wide skills.
- Threads, sessions, messages, task runs, tool calls, runtime history and raw secrets are never included.
- The protected default Workspace can only be restored into another protected default Workspace.
