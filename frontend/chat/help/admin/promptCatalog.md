Every text the platform agent reads ships with the product. You rarely need to change one.

### What you do here
- Find a prompt, tool description or MCP description.
- Override a text as a draft and compare it with the shipped text.
- Have the override reviewed by a second person.

### Good to know
- An override is a draft with a diff against the shipped text and needs a second reviewer. Each turn records which version it used.
- Agent and Workspace guidance belong in Agents and Instructions, not here.
