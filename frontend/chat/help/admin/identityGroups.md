---
title: Groups
---

Groups bundle people, so access is granted once instead of per user.

### What you do here
- Create a group with **+ New group**: a name and a description.
- Open a group to change its description and data access attributes, turn it off, or delete it.

### Next steps
- [Manage Workspaces](/chat?area=admin&tab=projects)
- [Check who can do what](/chat?area=admin&tab=identityAccess)

### Good to know
- Assign a group to a Workspace under the Workspace's Access settings to grant all active members access at once.
- Data access attributes (key = value) can be referenced by managed database row-level security rules to limit which rows members see.
