What each account can actually do right now, answered by the same checks the platform runs at sign-in and at the admin gate.

### What you do here
- See per account whether chat and admin access are allowed, and through which roles and groups.
- Use the fix button in a row to open the page that changes it.

### Next steps
- [Manage user accounts](/chat?area=admin&tab=users)
- [Manage roles](/chat?area=admin&tab=identityRoles)

### Good to know
- The checks are the account status, the sign-in permission, admin-capable roles and Workspace admin roles.
- **Workspaces** shows assigned / visible: assigned counts the Workspaces granted directly, through a global role or through an active group; visible is how many of them the account can open now (0 while it is inactive).
