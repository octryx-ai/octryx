Brand templates that generated decks, documents and spreadsheets follow.

### What you do here
- Create a profile from a template file (PPTX, DOCX or XLSX).
- Add more templates to a profile, each with a description.
- Set the presentation fallback.

### Next steps
- [Set the branding](/chat?area=admin&tab=branding)

### Good to know
- Each profile can hold several PPTX, DOCX and XLSX templates. Their descriptions help the agent choose the right one.
