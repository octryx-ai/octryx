Ask questions; the agent answers from the Workspace's sources and tools and shows where each answer comes from.

### What you do here
- The chat runs in the Workspace of the switch at the top of the rail; change it there.
- Leave the workflow and the model on **Automatic**, or pick one; the model pill names the model Automatic uses.
- **Off / Quick / Thorough** sets how long the agent thinks before answering.
- Open **Sources** under an answer to check it.
- Approve a tool step when the Workspace policy asks for it.

### Next steps

### Checking an answer
- "Sources · none cited" means the answer cites nothing; treat it as unsourced.
- Repository answers list the repository reads with commit and snapshot.
- "Finished, unverified" means no check accepted the answer.
- Opening a source uses your own permissions.

### Keyboard
- **Enter** sends; **Shift Enter** starts a new line.
- **/** opens the commands.
- **@** mentions an agent, a person, a tool or a file.

### Where the route is explained
- **Run details** in the chat header names the route: the workflow and why it was chosen (hover the route for the full reason).
