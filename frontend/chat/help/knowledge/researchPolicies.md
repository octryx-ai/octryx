title: Research profiles
---

How deep a research run goes: how many sources it collects, how many search rounds and child agents it may use, and how long the report is.

### What you do here
- Create a profile, then open it to change its settings and publish a version.
- Assign a published profile to the active Workspace, or clear the assignment to use the default.

### Next steps
- [Research websites](/chat?area=knowledge&tab=knowledgeResearch)
- [Search](/chat?area=knowledge&tab=knowledgeLibrary)

### Good to know
- A profile decides how deep a research run goes; which websites research may read is set under Research websites.
- Every change is saved as a new version: save it as a draft first, or create it published right away.
- A Workspace without an assignment uses the default deep research policy.
