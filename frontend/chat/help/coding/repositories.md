title: Repositories
---

The Workspace's repositories: the records workflow runs work in and the Knowledge git sources they come from.

### What you do here
- See every repository with where it comes from, what agents may do on it, its default branch and coding setup.
- Open a repository's latest workflow runs with **Runs**.
- **Set up for runs**: make a synced Knowledge source a repository record runs can use (Workspace owners).
- **Add a repository for runs** through one of the Workspace's code connections (Workspace owners).

### Next steps
- [Add a repository source](/chat?area=knowledge&tab=workspaceKnowledge&source=new)
- [Open coding sessions](/chat?area=coding&coding_view=sessions)

### Good to know
- **From** says where a repository comes from: a Knowledge source (Knowledge › Sources) or a connection.
- **Source sync** is a Knowledge source's state: Synced, Syncing, Waiting for sync, Waiting for upload or Sync failed.
- The coding setup is edited in Admin › Workspace › Repositories.
