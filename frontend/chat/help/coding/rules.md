title: Coding rules
---

Everything that limits the coding agent in this Workspace, one rule per row.

### What you do here
- Read what is blocked, what needs an approval, who approves and which checks run on every change.
- **What** says the kind of rule, **Applies to** what it stops, **Source** where it comes from: Built-in, the Workspace, a published policy.
- Open a row to see the rule, its source and where it is changed. A Workspace rule is changed in that panel and removed with **⋯** (Workspace admins); built-in rules apply to every Workspace and are read only.
- **Add rule** (Workspace admins) adds a command or file rule to this Workspace.

### Good to know
- A rule listed by the baseline and by the Workspace, or also published as a policy, is one row naming each source.
- A path rule says its pattern in words; hover the rule to see the pattern itself.
