# Release process (Demo Shop, fictional)

Releases go out on Tuesdays and Thursdays. A release needs:

- a green test run on the `main` branch,
- a change note that names the user-visible changes (for example a new shipping rule),
- a second person who approves the change note (four-eyes rule).

Hotfixes may skip the schedule, never the approval. Releases are frozen from 20 December to 3 January.
